PROJECT 

longthai

UX/UI • Website • User Research • Wireframe • Prototype • Design Systems • Mockup


a travel platform dedicated to exploring Thailand, offering curated recommendations for must-visit attractions, diverse accommodations, local eateries, and rest stops. with a special focus on supporting solo travelers.

UX/UI process

Research

Identify target users by researching their pain points and goals.

UX structure

by creating user flows and wireframes to define the content of each section and feature of the website. The wireframes focus on designing the website layout and arranging various components.

UI system

Develop a design system by establishing typography and color guidelines tailored to the website.

Prototype

Create both low- and high-fidelity prototypes, beginning with component-based design using Auto Layout.

Testing

UX Thinking





problem

CONCEPTUALIZED AND DESIGNED FEATURES THAT ADDRESS THE TARGET AUDIENCE’S NEEDS, DIFFERENTIATE THE BRAND FROM COMPETITORS, AND MAKE USERS FEEL THAT OUR APPLICATION PROVIDES A BETTER EXPERIENCE THAN SIMPLY SCANNING A QR CODE.





solution

By integrating real-time price comparison, curated travel content, smart budget planning, and verified reviews into a single platform, the solution streamlines trip planning and eliminates the complexity of using multiple travel tools.





result

While users responded positively to the application’s usability and core functionality, accessibility remains an area for improvement, particularly for visually impaired users who may experience difficulties with certain interactive elements.
